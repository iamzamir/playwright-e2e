What this repository does

Planning Space is where planners inspect and manipulate business data in the context of a process, subprocess, assumption, scenario, and scope. It builds pages dynamically from Link Management view mappings, portal UI configuration (lui/uiConfiguration/v1, cached in IndexedDB), Process Orchestration context, and planning/simulation services. It does not call UI Fields.

It is not a standalone portal. The Luminate Portal hosts it at LUMINATE_PORTAL_URL + PSLINK, provides login and shell navigation, and loads a runtime configuration generated into public/ before startup.

Functional capabilities

Dashboard and cards

  • Render configurable LUI dashboards and view groups.
  • Display pivot, table, chart, KPI, network, heatmap, tree, tabbed, and task cards.
  • Support card actions, resizing, drill-through, and row actions.
  • Load card types from shared @by/lui-* libraries.

Scenario planning

  • Create, select, compare, publish, and filter scenarios.
  • Support base/default, private/public, and child scenarios.
  • Propagate scenario context into cards and planning instances.
  • Expose scenario menus, side navigation, and headers.

Scope and navigation

  • Save, overwrite, delete, and map scope presets.
  • Apply quick filters, admin filters, draft filters, and defaults.
  • Navigate across process, subprocess, assumption, view, and supply-chain-action contexts.
  • Maintain breadcrumbs, last-accessed context, and power-bar history.

Planning workflows

  • Interactive planning, live blocks, dynamic constraints, and NPI.
  • On-demand MaaS execution and status tracking.
  • Supply-chain action wizard, popup, history, and scenario creation.
  • Guided workflows, collaboration, dirty-state protection, and alerts.
