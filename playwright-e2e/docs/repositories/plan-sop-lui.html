What this repository does

LUI is the user-facing control plane for Process Orchestration. Users create and operate processes and subprocesses, configure calendars and cycles, work with action items, search and navigate contexts, and administer views, attributes, schedules, transitions, and assumption types.

It is hosted by the Luminate Portal at LUMINATE_PORTAL_URL + POLINK. The repo also contains a legacy WebdriverIO suite under e2e/; new coverage belongs in the central Playwright repository.

Functional capabilities

Process operations

  • Create, edit, start, stop, close, and delete processes.
  • Manage subprocesses and adopt process variants.
  • Map procedures and respond to lifecycle triggers.
  • Show process, subprocess, and assumption summaries.

Calendar and planning structure

  • Manage calendars and nested cycles.
  • Assign calendars/cycles to process plans.
  • Configure schedule and structure.
  • Configure node transition graphs.

Views, scope, and navigation

  • Map planning views to view groups.
  • Search views and navigate quick links.
  • Save scope presets from assumptions and settings.
  • Use power bar, recently viewed, and context switcher.

Administration and work

  • Action-item create/edit/delete and bulk actions.
  • Data and attribute configuration.
  • Assumption type settings and scenario selection.
  • Lever-based planning and embedded iframe content.

Key interaction flows

Overflow row menu

sequenceDiagram
  participant T as Test or user
  participant R as Table row
  participant B as Three-dot button
  participant M as Menu
  participant I as Named menu item
  T->>R: locate target row
  T->>B: click button within row
  B->>M: open menu
  T->>M: wait until visible
  T->>I: select by accessible name
  I-->>T: action completes

The trigger lui-ccl-threedot-menu-icon-button occurs 63 times. Positional IDs such as action-menu-item-2 are fragile: reordering a menu clicks the wrong command without producing a locator failure.
