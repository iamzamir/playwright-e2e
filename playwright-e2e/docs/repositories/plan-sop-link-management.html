Link Management Service

What this repository does

Link Management answers a deceptively important question: which views should this process, subprocess, or assumption show, in what order, for this user? It stores the mapping between entity context and dashboards, optional procedure bindings, scope/filter presets, and user favourites.

Most failures do not produce a visible API error. A wrong mapping returns successfully and the frontend renders the wrong views. That makes this service an invisible dependency behind Planning Space view, scope, search, duplicate-view, and drill-through suites.

Functional capabilities

View catalog and mapping

  • Register dashboard views and query the catalog.
  • Map one or many views to process, subprocess, or assumption entities.
  • Search mappings for one entity or use projection-backed bulk search.
  • Update, remove one, or clear all mappings for an entity.

Procedures and scope

  • Bind procedures to mapped views.
  • Persist scope and quick-filter configuration for a view context.
  • Create, search, and clear user/admin filter presets.
  • Schedule procedure-to-view remapping under ShedLock.

User personalization

  • Add and remove favourite views per entity and user.
  • Support both ID-based and typed entity routes.
  • Filter view results by user visibility and LIAM permissions.
  • Maintain ordering via user-entity dashboard records.

Validation and migration

  • Validate an entity asynchronously and poll a job record.
  • Import/export view, procedure, and scope mappings.
  • Soft-delete and archive records.
  • Publish EFS audit-log events through Kafka.
