4. Method

  • Endpoints: every Spring @GetMapping/@PostMapping/@PutMapping/@DeleteMapping/@PatchMapping/@RequestMapping in each service's src/main, combined with the class-level prefix. Routes mapped by both a v1 and v2 controller count once. @Deprecated and @Profile("local") routes are listed but excluded from the denominator.
  • Evidence: Sending <METHOD> request to <URL> lines in the allure-results of the runs above, attributed to the spec that produced them. Gateway prefixes for Azure and Gravitee are stripped, and each URL matches the most specific route.
  • Exercised means at least one request from a test body. Setup only means the request happened only in beforeAll/afterAll. Via PO means PO calls the route downstream while serving a route the suite exercises (verified in the PO proxy services).
  • UI usage: method-level for PO and LM (JMeter coverage reports in jmeter/plans/); path-level literal scan of planning-mfe and lui source for Action Items and UI Fields, which can miss URLs built by concatenation.
  • Exercised does not mean fully asserted: depth varies by spec. See the PSR gap plans for the verified contracts.
