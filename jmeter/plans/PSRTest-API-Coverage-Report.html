Execution model

The plan combines a serialized token bootstrap with a finite, high-repetition business flow. These settings materially affect load volume and state safety.

Authentication bootstrap

One thread and one iteration request an Azure B2C client-credentials token. A JSON extractor captures access_token, then BeanShell stores it in a global JMeter property.

Business load

Defaults to 10 threads and 25 iterations with a one-second ramp. This produces a nominal 36,000 business sampler executions before considering plugin behavior or early failures.

Pacing and data

A 500 ms Constant Timer is in scope. LinksData.csv supplies one process plus 15 subprocess values, is shared across all threads, and recycles without stopping threads.

Parallel page flows

Eleven BlazeMeter Parallel Controller groups model listing, detail, cross-navigation, and action-item page traffic. The plugin is therefore a required execution dependency.

Coverage quality risks

These findings are directly supported by the JMX configuration and should be addressed before treating a green run as behavioral proof.

High

No explicit success criteria

Zero response assertions means the plan does not verify expected codes, content, schema, or business state. Correlation extractors are not assertions.

High

Shared state under concurrency

Mapping, clear, preset, tenant onboard, and action-item mutations run in a 10-thread group using shared recycled CSV data. Cross-thread interference can distort both failures and timings.

Medium

Identifier drift

The same plan mixes IntegratedBusinessPlanning, PSR1, fixed UUIDs, and composed subprocess names. The Gravitee sibling also differs on five exact action-item paths while matching all 41 normalized shapes.

Medium

Stale fixed dates and IDs

Action-item payloads include due dates from 2025 and fixed user/entity IDs. Environment changes can turn performance failures into test-data failures.

Medium

Duplicate operation noise

Fifty exact operations are placed 144 times. One sampler name, “Load Process With Page Size 5: Search Process,” is duplicated, which can merge metrics and hide which request instance failed.

Maintainability

Load-run overhead and legacy scripting

Four GUI listeners are enabled, and token sharing uses BeanShell. Prefer non-GUI result output and JSR223 Groovy or native property functions.
