## 3. Scope
Decision D3 (2026-10-09, user): **retire, don't delete.** `e2e/` and the WDIO workflows stay in the repo, marked retired and not in use.
- **In:** marking `e2e/` retired (`e2e/RETIRED.md`, `package.json` description); marking the three WDIO workflows retired (header comment, `[RETIRED]` name, cron commented out; they stay `disabled_manually`); updating the README, copilot-instructions, `AGENTS.md`, persona skills and the planner agent and skill so no current doc presents WDIO as active; archiving (not deleting) the migration agent and skill.
- **Out:** deleting `e2e/` or any workflow; the `legacy-wdio-final` tag (only needed if `e2e/` is deleted later); `playwright-po-iop-suite.yaml` (disabled, but it runs Playwright on Sauce, not WDIO); other docs drift (T8.2).

## 4. Implementation steps
1. **D3.** Answered by the user on 2026-10-09: keep `e2e/` and its workflows, marked retired. Record it in the master plan.
2. **Mark `e2e/` retired:** add `e2e/RETIRED.md` (retired date, not in use, where the workflows and the archived migration files went, where new tests go) and set `e2e/package.json` `description` to say it's retired.
3. **Mark the WDIO workflows retired:** in `complete-qa-suite.yaml`, `po-qa-suite.yaml` and `ps-iop-suite-windows.yaml`, add a `# RETIRED` header, rename to `[RETIRED] <name> (WDIO)` and comment out the `schedule:` block, so re-enabling one can't start a nightly run. Before renaming, check the `workflow_run` triggers in `nightly-triage.yaml` and `triage/suites.json` for the names; none are expected.
4. **Root README:** say that WDIO is retired; drop the WDIO install, quick-start and scripts sections; mark the three workflow rows **Retired**.
5. **Instructions and agents:** mark `e2e/` retired in `.github/copilot-instructions.md` "What this repo is". In `playwright-planner.agent.md` and the `plan-playwright-tests` skill, replace the WDIO gap analysis with a Playwright coverage gap analysis. Move `playwright-migration.agent.md` and the `migrate-wdio-spec-to-playwright` skill (a prompt until PR #782) to `.github/archive/` with a header line. Update the `role-playwright-automation` and `role-sdet-architect` skills, `AGENTS.md` and `playwright-e2e/README.md` to match.
6. Dependabot (T2.5): make sure no `/e2e` entry exists.
