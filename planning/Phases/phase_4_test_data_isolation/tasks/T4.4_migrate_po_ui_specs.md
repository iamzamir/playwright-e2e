## 4. Implementation steps
1. Follow T4.3 section 4 steps 1–7, per folder, in this order: ProcessBatch → ScopeBatch → ActionItemsBatch → Calendar → ViewManagerBatch. One commit per folder in one PR (the folders are small), or separate PRs if a folder needs discussion.
2. **Processes** created through the UI: register as `process` with the name, and let the deleter call `deleteProcessWithReferences` (it removes the references first).
3. **Action items:** register as `actionItem` with the id if the UI flow returns it; otherwise by name with the process context.
4. Run each folder with its npm script, twice in a row:
   ```bash
   cd playwright-e2e
   npm run test:interop:poui:processbatch
   npm run test:interop:poui:scope
   npm run test:interop:poui:actionitems
   npm run test:interop:poui:calendar
   ```
   (Check the script names in `package.json`; use `test:interop:poui:other` for the rest.)
