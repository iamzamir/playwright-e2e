## 1. Problem
The four specs under `tests/_framework/` test the framework itself: the `compareTwoValues` ledger (T3.1), `uniqueName` (T4.1), and the `createdEntities` registry and its deleters (T4.2). They need no browser, credentials or environment, but no workflow ran them. `pr-checks` only listed them (`--list`), so a PR could break the ledger or a deleter and still pass.

## 2. Evidence (verified 2026-11-11 on `origin/main` @ `339751f`)
- `tests/TestSuites/_unscheduled.json` lists the four specs as "run standalone".
- `grep -n _framework .github/workflows/*.yaml` → no match.
- `pr-checks.yaml` runs no Playwright test, and installs no browsers (`npm ci --ignore-scripts`).
- No `_framework` test uses a `page`, `context` or `browser` fixture.

Re-check:
```bash
grep -rn "_framework" .github/workflows
cd playwright-e2e && PW_ENABLE_GLOBAL_SETUP=false USE_SPECIFIC_TESTS=false ENVIRONMENT=INTEROP npx playwright test tests/_framework --config=configs/playwright.config.ts --workers=2
```

## 3. Scope
- **In:** one `Framework self-tests` step in `pr-checks.yaml` (job `Quality Checks`) and its line in the step summary.
- **Out:** running UI or API specs on PRs (that needs D7).

## 4. Implementation steps
1. After "Environment config unit tests", add a step: `npx playwright test tests/_framework --config=configs/playwright.config.ts --workers=2` with `PW_ENABLE_GLOBAL_SETUP=false`, `USE_SPECIFIC_TESTS=false` and `ENVIRONMENT=INTEROP` (the same env as the list step).
2. Add a "Framework Self-Tests" row to the step summary.
