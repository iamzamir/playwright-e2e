## 1. Problem
`Test_003_ScenarioVisibilityFilter` (15 tests then, 10 since Assumption was removed on 2026-10-27; 7.3 min) and `Test_006_ScenarioUsersFilter` (12 tests, 7.8 min) were the two longest Planning Space files on 2026-10-24. Most of their tests apply one filter value to a list that comes straight from `simulations/search`. The T9.1 pilot proves the Visibility filters in the mocked tier. This task finishes the move: Users filter mocked too, and both real specs cut down to the one real check each feature needs.

- Both are in `ScenarioBatchA.json`.
- Assumption scenarios are no longer supported (2026-10-27). `Test_006` still has an Assumption context (4 tests): confirm with the spec owner and remove it here, as was done for `Test_003`.
