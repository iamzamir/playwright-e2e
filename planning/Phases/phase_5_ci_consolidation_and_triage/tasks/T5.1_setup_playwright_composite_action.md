## 1. Problem
Every test workflow repeats the same 5–7 steps to get a runner ready: disk clean-up, Node setup, JFrog `.npmrc`, `npm ci`, the apt-source workaround, `playwright install`, and Xvfb for headed runs. They drift (for example `node-version` written as `'24.x'` in some files and `"24.x"` in another) and every fix needs ten edits.

## 4. Implementation steps
1. Diff the setup steps across the 6 active test workflows (PS UI, PO UI, PO backend, visual, performance, custom). List the differences (Node version, browser channel, Xvfb on or off, disk clean-up on or off) in the PR. Every difference becomes an input, or is dropped with a reason.
2. Create `.github/actions/setup-playwright/action.yml`:
   ```yaml
   name: Setup Playwright
   description: Node, JFrog auth, npm ci and browsers for playwright-e2e
   inputs:                  # every input needs a description: GitHub's action metadata schema requires it
     node-version:
       description: Node.js version passed to actions/setup-node
       required: false
       default: '24.x'
     install-browsers:
       description: "'true' to install Playwright browsers and OS dependencies (every test workflow needs it today, the PO backend included)"
       required: false
       default: 'true'
     browser:
       description: Browser or channel for `npx playwright install` (match what the workflows install today)
       required: false
       default: 'chrome'
     xvfb:
       description: "'true' to install Xvfb for headed runs"
       required: false
       default: 'false'
     free-disk:
       description: "'true' to run the disk clean-up step before installing"
       required: false
       default: 'false'
     jfrog-token:
       description: JFrog npm token. Pass it from the caller (for example `secrets.<name>`); a composite action can't read secrets itself
       required: true
   runs:
     using: composite
     steps:
       - uses: actions/setup-node@<sha>   # cache npm with cache-dependency-path: playwright-e2e/package-lock.json
       - shell: bash
         run: <JFrog .npmrc steps copied verbatim>
         env: { JFROG_TOKEN: '${{ inputs.jfrog-token }}' }
       - shell: bash
         working-directory: playwright-e2e
         run: npm ci
       - if: inputs.install-browsers == 'true'
         shell: bash
         working-directory: playwright-e2e
         run: <apt-source workaround + npx playwright install --with-deps ${{ inputs.browser }}, copied verbatim>
       - if: inputs.xvfb == 'true'
         shell: bash
         run: sudo apt-get install -y xvfb
   ```
   Copy commands verbatim from the reference workflow. Don't "improve" them in this task.
3. Pilot: replace the setup steps in `visual-automation-test.yaml` with `- uses: ./.github/actions/setup-playwright` (after `actions/checkout`).
4. Dispatch the visual workflow on the branch (with the user's OK) and compare with the last run on `main`: same test count, and setup time within ±20%.
