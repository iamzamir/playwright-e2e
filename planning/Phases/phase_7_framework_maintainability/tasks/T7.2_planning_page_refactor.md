## 4. Implementation steps (per slice)
1. **Pick the slice** with the most ranked failures (T7.1). List its methods and their callers (`grep -rn "planningPage.<method>(" tests pageobjects`).
2. **Create the component object** `pageobjects/planning/<region>.component.ts` extending the same base the POMs use (`pageobjects/page.ts`). It takes the page and the MFE frame accessor, and exposes the region's locators as private getters and actions as public methods.
3. **Locators.** For each XPath in the slice, find the element's `data-testid` in `docs/repositories/plan-sop-planning-mfe/ui-inventory.md` (or the lui inventory), or its role and accessible name. Confirm on INTEROP with the IDE browser (healer's live-reproduction steps). Use `getByRole` > `getByTestId` > label, placeholder, text > CSS.
4. **Waits.** Replace `waitForTimeout(n)` with the condition it was waiting for: `await expect(locator).toBeVisible()`, `toBeHidden()` for loaders, or `page.waitForResponse(url-part)` for data loads. Replace `if (await x.isVisible())` used as a check with `await expect(x).toBeVisible()`. Where it's genuinely optional ("close the toast if present"), use `x.waitFor({ state: 'visible', timeout: getTimeout('SHORT') }).then(() => true, () => false)`.
5. **Delegate.** In `PlanningPage`, keep each public method's signature and make it call the component (`return this.leftPane.openComponent(name);`). Mark it `/** @deprecated use planningPage.leftPane.openComponent */` only when the component method is meant for direct use.
6. **Run** the specs that call the slice's methods (from step 1) on INTEROP, in isolation and then the folder; `--repeat-each=3` for previously flaky ones.
7. `npx eslint . --prune-suppressions` to lock in the lower counts (`npm run lint:baseline` also works but re-suppresses everything from scratch).
